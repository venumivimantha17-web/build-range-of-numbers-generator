# Build a Range of Numbers Generator

A Python project that demonstrates how to use **recursion** to generate a list of consecutive integers between a starting number and an ending number.

## Description

The `range_of_numbers` function takes two integers, `start_num` and `end_num`, and returns a list containing every consecutive integer from `start_num` to `end_num`, including both values.

The function uses recursion instead of loops or Python's built-in `range()` function.

## Example

```python
range_of_numbers(3, 9)
